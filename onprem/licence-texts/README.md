# Canonical licence texts

Used by `onprem/third-party-notices.py` only for crates that publish no licence
file of their own: the text of the licence Cove chose for them, under a
copyright line built from the crate's authors and repository. Taken 2026-10-29
from crates that ship them unmodified: Apache-2.0 (cpufeatures 0.3.0
LICENSE-APACHE), BSL-1.0 (whoami 1.6.1 LICENSE_BOOST), Zlib (cursor-icon 1.2.0
LICENSE-ZLIB, its copyright line removed), MPL-2.0 (from cssparser-0.34.0 LICENSE), BSD-3-Clause (the SPDX
text, without its copyright line). MIT.txt is the MIT permission body;
the generator puts the copyright line above it.
